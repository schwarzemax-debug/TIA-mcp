# Samples

Beispielkonfigurationen für MCP-Clients. `<NAME>` durch den Windows-Benutzernamen ersetzen und Pfade anpassen.

- `claude-code/.mcp.json` – Claude Code (Projekt-Config; alternativ `claude mcp add`, siehe README).
- `claude/claude_desktop_config.json` – Claude Desktop (`%APPDATA%\Claude\claude_desktop_config.json`).
- `vscode/mcp.json` – VS Code / GitHub Copilot.
- `tia.json` – Exportformate fuer den Export-Ordner (das Installationsskript kopiert sie, falls dort keine liegt).
